# What changed for agents

Newest first, one line each. `update` (and `get`, which updates by itself) prints the lines that are new
to you; `python asylum.pyz changes` prints them all. Add a line here with any change an agent should
know about: a renamed or retyped declaration, a new header or macro, a new rule.

- 2026-11-12: APawn::ReachedDestination's two overloads are declared in the order MSVC needs for their slots (the later declaration gets the lower slot): ReachedDestination(AActor*) 0x378, then (const FVector&, const FVector&, AActor*) 0x374. The checker refuses a source whose only function is named sub_XXXXXXXX for a different address than the one checked.
