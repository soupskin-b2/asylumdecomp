# What changed for agents

Newest first, one line each. `update` (and `get`, which updates by itself) prints the lines that are new
to you; `python asylum.pyz changes` prints them all. Add a line here with any change an agent should
know about: a renamed or retyped declaration, a new header or macro, a new rule.

- 2026-11-12: Script.h has the optional-out macros: P_GET_{INT,FLOAT,BYTE,UBOOL}_OPTX_REF(v, def), P_GET_OBJECT_OPTX_REF(Class, v, def), P_GET_STR_OPTX_REF(v, def) and P_GET_STRUCT_OPTX_REF(Struct, v) (no default: the temp stays uninitialized); each also gives pV, the caller's variable or NULL (FindClosestBone(Loc, pBoneLocation, ..)). USettings' 41 virtuals (0x10c..0x1b4) and 21 of UOnlineProfileSettings' are named and typed (GetStringSettingValue, GetPropertyRange, UpdateFromURL, GetProfileSettingValueInt ...); UUIRoot::GetCursorPosition and USkeletalMeshComponent::FindClosestBone declared.
- 2026-11-12: wxWidgets: `#include "ue3/Wx.h"` gives the real wx 2.8.6 headers, configured as the game's wx DLLs were built (verified: all 3345 exported vtable slots and 270 class sizes match). Write editor code as UE3 did: `class WxDlgAddSpecial : public wxDialog`, `GDlgAddSpecial->Show(TRUE)`, handlers taking `wxCommandEvent& In`; no hand-made wx classes with placeholder virtuals. SIZE_T is now unsigned long, as in <basetsd.h>.
- 2026-11-12: ue3/GFx.h: Scaleform's GFxMovieView (Advance at 0x78, other slots placeholders), the engine's FGFxMovie (UGFxMovie::pMovie; pView at 0x34) and GGFxEngine (0x026caed4).
- 2026-11-12: ue3/PhysX.h: the game's NxCloth and NxSoftBody interfaces at the slots its code uses (others are _slot_XXX placeholders). USkeletalMeshComponent::ClothSim / SoftBodySim are void* (cast to NxCloth* / NxSoftBody*), and the cloth accessors the execs inline are declared (GetCloth*/SetCloth*, SetClothSleep, AttachClothToCollidingShapes, WakeSoftBody).
- 2026-11-12: math types have UE3's constructors: FVector() / explicit FVector(FLOAT) / FVector(X,Y,Z), FPlane(X,Y,Z,W) / FPlane(FVector,W), FMatrix(4 planes), FTranslationMatrix(FVector), FBasedPosition(); FORCEINLINE is defined. FVector is no longer an aggregate: write FVector(0.f, 0.f, 0.f), not {0,0,0}. UCanvas::Canvas is a class FCanvas* (FCanvas::PushRelativeTransform declared).
- 2026-11-12: 41 more virtuals named and typed from the natives that call them (they took INT for an object): AController RouteCache_RemoveItem, APawn IsValidTargetFor/ReachedDestination/AddGoalEvaluator/DrawPathStep, ANavigationPoint IsUsableAnchorFor/CanTeleport, UReachSpec CostFor(APawn*), UPrimitiveComponent SetLightEnvironment, UMaterialInstance SetParent, ARPlayerController's ambient-sound slots, ARForensicsDevice EvidenceRegister*, URInteractionManager Register/UnRegisterActor and more (grep Classes.h). Call them by name: no (INT) casts.
- 2026-11-12: libjpeg is stock 6b after all: jpeg_consume_input's size included padding (now 195), and 6 unnamed functions were 6b's own (jpeg_input_complete, write_marker_byte, jpeg_idct_1x1, prescan_quantize, jpeg_finish_output, start_pass_huff_decoder): all matched.
- 2026-11-12: the game's script enums are in ue3/Enums.h (included by Classes.h): 419 enums with their values (ESplitScreenRenderMode, ENetMode, EScreenInputMode ...). Fields keep BYTE; compare and assign with the names, and don't define these enums yourself. Left out (their names clash in C++): the list at the top of Enums.h.
- 2026-11-12: FSettingsData has its destructor (~FSettingsData, out of line), and USettings declares EmptySettingsData, Get/SetSettingsDataFloat/Int, GetSettingsDataString: natives taking an FSettingsData use P_GET_STRUCT_REF(FSettingsData, Data).
- 2026-11-12: FVector4 is 16-byte aligned with a (0,0,0,1) default constructor, as in UE3 (script structs keep FVector4Unaligned members). UUIScreenObject declares CanvasToScreen, PixelToScreen, ScreenToPixel, ScreenToCanvas.
- 2026-11-12: function boundaries fixed: 01a14210 (error_exit, plus output_message at 01a14230), 0180df60 (_tr_flush_block, 517 bytes; the wx import thunks after it are their own functions), 0179f126, 017c8e4b, 017c8e85, 01c2ea80, 01c31d10 (each held two functions).
